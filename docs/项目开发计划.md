# 基于Vue的个人代码学习错题集与编程笔记复盘系统 —— 项目开发计划

> 适用：某高校 软件工程专业 毕业设计
> 文档版本：v1.0（2026-09-09） ｜ 配套产物：`server/`（后端骨架）+ `web/`（前端骨架）+ `sql/`（建库脚本）

## 一、项目概述

### 1.1 项目定位

面向计算机专业学生的个人编程学习资料管理平台：把刷题、实训、项目开发中产生的**代码报错、逻辑漏洞、接口异常**沉淀为可检索、可复盘、可统计的错题集，配合在线代码笔记、每日复盘计划与社区互助问答，形成"记录 → 复盘 → 统计 → 互助"的闭环学习档案。同时为院校提供全局学情监控与内容管控后台。

### 1.2 系统组成

| 端 | 使用角色 | 功能域 |
|---|---|---|
| 前台学生端 | 学生（student） | 账号安全中心、错题本、代码笔记、每日复盘计划、智能检索、数据可视化、互助问答 |
| 后台管理端 | 教师=普通管理员（teacher）、超级管理员（admin） | 用户管理、内容审核、数据大屏、公告推送、权限分级与操作日志 |

### 1.3 技术选型（已锁定）

| 层 | 技术 | 版本 | 选择理由 |
|---|---|---|---|
| 前端框架 | Vue 3（组合式 API + `<script setup>`） | ^3.4 | 现代主流，响应式 Proxy，生态最好 |
| 构建工具 | Vite | ^5.4 | 秒级冷启动，HMR 极快 |
| 组件库 | Element Plus | ^2.8 | 组件最全、中文文档、毕设答辩好讲 |
| 图表 | ECharts | ^5.5 | 柱状/饼图/折线/大屏全覆盖 |
| 富文本 | wangEditor | ^5.1 | 中文文档好、支持代码块 |
| 代码高亮 | highlight.js | ^11.10 | 轻量，错题/笔记/问答通用 |
| 状态/路由 | Pinia + Vue Router | 2.x / 4.x | 官方标准组合 |
| 后端框架 | Spring Boot | 2.7.18 | JDK 8 兼容线最终版，中文资料最丰富 |
| ORM | MyBatis-Plus | 3.5.5 | BaseMapper 零 XML CRUD、分页插件、逻辑删除 |
| 数据库 | MySQL | 8.0 | utf8mb4 全字符集 |
| 鉴权 | JWT（jjwt 0.11.5）+ BCrypt（spring-security-crypto 5.7.11） | — | 无状态鉴权 + 加盐哈希 |
| 工具库 | Hutool | 5.8.25 | 图形验证码、JSON、文件 |
| JDK | Zulu/Oracle JDK 8（1.8） | 1.8.202+ | 学校机房/教程最大公约数 |
| 开发环境 | IntelliJ IDEA Ultimate（学生免费授权）| 2023.3+ | 后端必选；前端同窗口运行 |
| Node | Node.js LTS | 20.x | Vite 5 要求 ≥18 |

**架构**：前后端分离。前端 `5173`（Vite dev），后端 `8080` + 统一 `context-path=/api`；开发期前端请求经 vite proxy 转发，后端另配 CORS 双保险；鉴权用 JWT（`Authorization: Bearer`），密码与密保答案 BCrypt 加密入库。

### 4.2 与中期报告"八大核心表"口径的归并说明（论文可直接引用）

中期报告口径：用户、管理员、学生、教师、错题、笔记、复盘、收藏 共 8 张。最终设计演进为 16 张：

1. **用户/管理员/学生/教师 四表合并为单 user 表 + role 字段**：三类角色字段重合度超 80%（用户名、密码、昵称、头像、状态完全一致），合表消除三套登录逻辑与跨表统计 JOIN；用 `@RequireRole` 注解做接口级权限。
2. **收藏不独立建表**：本系统收藏是"学生对自己错题"的 1:1 布尔标记，并入 `mistake.is_favorite`；若未来扩展"收藏他人内容"再升级为通用收藏表。
3. **复盘一表拆四表**：review_plan（设置）/review_task（每日任务+自动打勾）/check_in（打卡流水）/study_time_log（时长流水），统计图表各有专属数据源，SQL 最简单。
4. **规范化扩展**：标签多对多拆 mistake_tag + mistake_tag_rel；笔记分类拆 note_category；新增公告/已读/敏感词/操作日志支撑管理端。

### 4.3 关键字段设计要点

- **逻辑删除**：业务主表统一 `deleted TINYINT DEFAULT 0`，MyBatis-Plus 全局逻辑删除自动拼 `deleted=0`；"一键删除归档"即 `deleted=1`（回收站语义），归档查询手写 SQL 绕过——把逻辑删除从技术特性讲成业务语义。
- **审核状态机**：`audit_status` 0待审核/1正常/2已下架。错题默认 1（私有内容，管理员巡查可下架）；笔记"私密恒 1，转公开置 0 进审核流，通过后才进广场"——任何进入公域的内容先过审核。
- **多图存储**：`mistake.images` 存 URL 的 JSON 数组字符串（附属数据读多写少，反范式冗余省一次 JOIN）。
- **全文检索选型**：`LIKE '%kw%'` + `idx_user_create` 先收敛到个人数据范围（百~千级行），毫秒级够用；不引 ngram/ES（演示机配置漂移风险、过度设计），论文写明可演进路径。

## 五、核心机制设计（答辩讲述点）

1. **JWT 无状态鉴权 + 三层权限防护**：token 自携带 userId/role，服务端零会话；URL 前缀拦截 → `@RequireRole` 角色裁决 → Service 层 `user_id = 当前登录人` 归属校验（防横向越权）。密码与密保答案 BCrypt 加盐入库，永不出网（UserInfoVO 脱敏）。
2. **图形验证码防爆破**：Hutool LineCaptcha 生成，答案存服务端内存 Map（5 分钟过期、一次性使用），登录强制校验；失败即刷新。
3. **敏感词自动拦截收口在 Service 层**：发布错题/笔记/问答/评论五个入口统一 `assertClean`，词库内存加载 O(文本×词长) 零查库，管理员维护词表后热刷新。
4. **复盘闭环**：计划快照 → 每日任务行 → 完成复习打勾（防重复计数 reviewed_ids）→ 达标自动打卡 → 日历五态着色 → 登录未完成提醒（弹窗+角标）。
5. **操作日志 AOP 非侵入**：`@OperationLog` 注解 + 环绕通知，自动记录操作人/模块/动作/参数（脱敏）/IP/耗时/成败，业务代码零侵入；仅超管可查——把"权限分级"讲实。
6. **笔记双轨备份**：`@Scheduled(cron)` 每天凌晨 2 点全量导出 JSON 落盘 + 学生端手动一键备份，备份文件列表可查。
7. **公告已读多对多**：announcement × announcement_read 差集求未读，登录后弹窗推送，管理端可见已读/未读人数。
8. **统计聚合**：全部单表 GROUP BY 走索引（不做大 JOIN），ECharts 双主题统一封装；大屏数据近 30 天按日序列前端补零对齐。

## 六、前端 UI 设计规范（"前端要美观"的落地保障）

**设计基调**：浅色开发者工具风——深侧栏（#0F172A）+ 浅灰内容底（#F5F7FB）+ 白卡片三层纵深；品牌主色靛蓝紫 #6366F1 → #8B5CF6 渐变；代码等宽字体 JetBrains Mono（本地打包，断网可用）。

- **设计令牌**：`variables.css` 全量 CSS 变量（品牌色 7 级、语义色 4 组、Slate 灰阶 11 级、圆角 7 档、阴影 6 档、间距 9 档），组件禁止手写 HEX。
- **Element Plus 换肤**：`element-overrides.css` 九级主色按官方混色算法精确覆盖（消灭默认蓝 #409EFF）。
- **错误类型四色语义**：语法橙/逻辑紫/接口蓝/环境青，徽标、筛选、详情、图表四处同色系。
- **亮点页**：登录页左右分栏（品牌渐变 + 仿真代码窗 + 特性胶囊）；仪表盘欢迎横幅 + 渐变统计卡（CountUp 数字滚动）；错题卡片栅格（3px 类型顶条 + 深色代码预览渐隐 + 标签彩色 chips + 收藏星弹跳动画）；复盘日历五态格子；数据大屏深色发光面板（ScreenPanel 纯 CSS 光角）。
- **体验细节**：路由过渡 fade-slide、表格斑马纹 + 悬浮行、el-skeleton 骨架屏防白屏、EmptyState 温度文案、NProgress 顶部进度条、响应式断点 1366/1920 双档必过。

## 七、内置账号与数据策略（真实数据原则）

**系统不内置任何演示/示例业务数据**：页面上出现的每一条错题、笔记、打卡、问答，都是用户真实操作写入数据库产生的；空页面走统一 EmptyState 空状态引导。

后端启动时 `DataInitializer` 只播种系统配置级数据（幂等，重复启动不重复）：

| 内容 | 明细 |
|---|---|
| 内置账号 | `admin/admin123`（超管，不可删）、`teacher01/123456`（教师，权限分级对照） |
| 系统内置笔记分类 | Vue学习笔记/数据库笔记/框架笔记/Java基础/算法笔记/项目实战/随笔心得（user_id=0 全员共用） |
| 默认敏感词库 | 代考/代写/代做/答案售卖/考试作弊/外挂/刷单/包过（管理端可增删、即时生效） |

学生账号一律通过登录页注册产生；答辩演示前用手册第 8 节路线，现场注册账号并录入真实错题/笔记即可。
