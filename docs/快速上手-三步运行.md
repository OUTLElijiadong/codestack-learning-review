# 快速上手：装好就跑（Windows）

> **全程不需要命令行**——数据库会在后端第一次启动时自动创建（自动建库、自动建 16 张表、自动创建内置账号）。
> 只需要装 3 个软件：**JDK、MySQL 8、IDEA**（下载地址见《Windows环境搭建与运行手册》第 1 节；装 MySQL 时自己设的 root 密码要记住）。
> **JDK 版本不挑**：8 / 11 / 17 / 21 / 25 都可以（已实测 8、21、25 完整跑通），电脑上已经装了哪个就用哪个，不用专门再装。

---

## 第 1 步：解压 + 打开

1. 把压缩包解压到 `D:\code\`（解压出来就是 `code-review-system` 文件夹）
2. 打开 IDEA → File → Open → 选择 `D:\code\code-review-system\server` 目录
3. 第一次打开会自动下载依赖：等右下角进度条全部走完（几分钟，只需等这一次）

## 第 2 步：填数据库密码并启动

1. 在 IDEA 左侧打开 `src/main/resources/application.yml`，找到 `password: 123456`，改成**你装 MySQL 时设置的 root 密码**，按 Ctrl+S 保存
2. 左侧项目树找到 `src/main/java/com/wy/review/ReviewServerApplication`，右键 → **Run 'ReviewServerApplication'**
3. 控制台出现 `Tomcat started on port(s): 8080` 即启动成功（第一次启动会顺带自动建库建表，控制台有「自动建表完成」日志）

## 第 3 步：打开系统

浏览器（Edge/Chrome）访问：

```
http://localhost:8080/api
```

| 账号 | 密码 | 身份 |
|------|------|------|
| admin | admin123 | 超级管理员 |
| teacher01 | 123456 | 教师 |
| student01 ~ student05 | 123456 | 学生（演示主力账号） |

首次启动会自动创建 42 名仿真同学和整套业务数据（错题、笔记、复盘打卡、学习时长、问答、公告），大屏和学生端开箱即有内容；之后所有数据随真实操作实时变化。也可以在登录页「立即注册」新学生。**建议把网址收藏，或右键桌面→新建→快捷方式 填这个网址。**

---

## 以后再运行

MySQL 开机自启不用管；每次只要 IDEA 里点绿色三角 ▶ 运行 `ReviewServerApplication`，然后开浏览器访问 `http://localhost:8080/api`。已有数据不会受影响（建表脚本只在数据库为空时执行一次）。

## 常见问题

| 现象 | 原因与解决 |
|------|-----------|
| **IDEA 里点不了运行 / 运行报一堆红字** | 按顺序对照三件事：① 确认打开的是 `server` 文件夹本身（不是外层 code-review-system）：File → Project Structure 里能看到 pom 才对；② File → Project Structure → Project，SDK 选 `1.8`（没有就点 Add JDK → 选 JDK 安装目录），Language level 选 `8`；③ 右下角是否还有 Maven 下载进度条——**没走完之前运行必报错**，先把 `File → Settings → … → Maven` 的 User settings file 勾 Override 并选择 `docs\maven-settings.xml`，再点右侧 Maven 面板的刷新图标，等进度条走完（阿里云镜像 3~10 分钟）。报「找不到符号」→ `Settings → Build → Compiler → Annotation Processors` 勾选 Enable annotation processing。详见手册第 3 节 |
| 编译报 `java.lang.ExceptionInInitializerError` / `TypeTag :: UNKNOWN` | **编译用的 JDK 太新，不是 JDK 8**（常见于装成了新版 JDK 或选了 IDEA 自带 JBR）。两处都改回 1.8：① File → Project Structure → Project，SDK 选 `1.8`；② Settings → Build Tools → Maven → Runner，JRE 选 `1.8`。改完重新运行（2026-09-10 后的包已把 Lombok 升到 1.18.48 并实测 8~25 全兼容，一般改完 SDK 即可；嫌麻烦也可以不改——新版 JDK 直接编译运行都行） |
| 编译报「程序包 xxx 不存在」（如 jackson / aspectj / lombok） | **Maven 依赖没下载完整**（这些包都是 pom 里 spring-boot-starter-web / aop 的传递依赖，代码不缺声明）。修复：① 确认 `File → Settings → … → Maven` 的 User settings file 勾了 Override 并选中 `docs\maven-settings.xml`；② 点 IDEA 右侧 Maven 面板左上角**刷新图标（Reload All Maven Projects）**；③ 看右下角进度条走完（阿里云镜像 3~10 分钟），**没走完就运行必报这个错**；④ 还不行就删掉 `C:\Users\你的用户名\.m2\repository` 文件夹后重新刷新（清掉损坏缓存重下） |
| 控制台报 `Access denied for user 'root'` | application.yml 里的密码和 MySQL 实际密码不一致，改对保存后重新运行 |
| 控制台报 `Communications link failure` 或 `Connection refused` | MySQL 服务没启动：Win+R 输入 `services.msc` 回车，找到 MySQL80，右键「启动」 |
| 网页打不开 / 一直转圈 | 后端没启动成功，回 IDEA 看控制台红色报错；或 8080 端口被占（关掉占用程序） |
| **运行的界面还是旧的**（没有身份下拉/收藏总览/浅色大屏） | 跑的不是最新包或旧文件残留：① 确认解压的是**文件名带 v2-2026-09-22 的最新包**；② 覆盖解压过的话，删除 `server\target` 文件夹，IDEA 里 Build → Rebuild Project 后再运行；③ 浏览器按 Ctrl+F5 强制刷新。验证方法：登录页左下角应有「v2.0 · 答辩整改版」字样，控制台启动时会打印版本横幅 |
| 登录提示验证码错误 | 验证码 5 分钟内有效且一次性，点图片换一张再输 |
| 想改前端代码再发布 | 需要 Node.js，见《Windows环境搭建与运行手册》开发模式章节（选读） |

> 完整版手册（含 JDK 环境变量配置、IDEA 截图式步骤、开发模式）见同目录《Windows环境搭建与运行手册.md》。
> 说明：本版本**无需再执行 `sql\schema.sql`**——数据库为空时后端会自动初始化；那份脚本保留给习惯手工建库的情况，两种方式效果一致。
