# 接口清单（REST API 速查表）

> 统一约定：
> - 所有接口实际前缀为 `http://localhost:8080/api`（context-path=/api）；前端 axios baseURL 已配 `/api`，api 层路径省略此前缀
> - 除"公开"接口外，请求头需携带 `Authorization: Bearer <token>`
> - 返回统一为 `{"code": 200, "msg": "操作成功", "data": ...}`；401=未登录/失效，403=无权限
> - 分页参数统一 `pageNum` / `pageSize`，返回 `{total, pages, current, size, list}`
> - 角色：student 学生 / teacher 教师(普通管理员) / admin 超级管理员

## 0. 公共接口

| 方法 | 路径 | 说明 | 角色 |
|---|---|---|---|
| GET | /auth/captcha | 图形验证码（Hutool LineCaptcha，返回 uuid + Base64 图，5 分钟有效、一次性） | 公开 |
| POST | /auth/register | 学生注册（用户名/密码/确认密码/昵称/密保问题/密保答案） | 公开 |
| POST | /auth/login | 密码登录（验证码 → BCrypt 校验 → 冻结检查 → 签发 JWT） | 公开 |
| GET | /auth/security-question?username= | 找回密码第一步：取该账号的密保问题 | 公开 |
| POST | /auth/reset-password | 找回密码第二步：密保答案比对通过后重置 | 公开 |
| POST | /auth/logout | 退出登录（JWT 无状态，仅留痕） | 登录 |
| GET | /auth/profile | 当前登录人信息（脱敏；刷新页面恢复状态用） | 登录 |
| PUT | /auth/profile | 修改资料（昵称/学习方向/专业/班级/简介/邮箱/手机/性别） | 登录 |
| PUT | /auth/profile/password | 修改登录密码（验旧密码） | 登录 |
| PUT | /auth/profile/avatar | 修改头像（body: {"avatar": "url"}） | 登录 |
| PUT | /auth/profile/security | 修改密保（需登录密码验身份） | 登录 |
| POST | /common/upload | 图片上传（form-data 键 file；jpg/png/gif/webp ≤10MB；返回 /api/uploads/... 可访问 URL） | 登录 |
| GET | /api/uploads/** | 上传文件静态访问 | 公开 |
